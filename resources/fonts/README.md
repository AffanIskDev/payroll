# Font Roboto

Subset latin Roboto (Regular, Medium, Bold, Italic) dari Fontsource
(`cdn.jsdelivr.net/fontsource/fonts/roboto`), lisensi SIL Open Font License 1.1.
Dipakai oleh dompdf untuk slip gaji & Formulir 1721-A1 (sama dengan font contoh slip),
dan disalin ke `public/fonts` untuk antarmuka web.
